Constructor bug
---------------

The upper limit check permits values through 0x3000. The intended 0xd0 check
is compiled as a byte comparison against BPL, so only logical_len & 0xff is
checked. A value such as 0x1d0 therefore passes.

Write bug
---------

For end = offset + data_length, write() accepts the request when either:

    ((end ^ object->guard) & 0xfff) <= 0xd0

or the ordinary end <= 0xd0 bound holds. Once the next object's guard is
leaked, an attacker can pad an overflow until the first expression succeeds.
The copy destination is object+0x30+offset.

Arbitrary read
--------------

show() returns PyBytes_FromStringAndSize(object->display_pointer,
object->logical_length). Overflowing a neighboring object therefore turns its
+0x20 and +0x10 fields into an arbitrary pointer/length read primitive.

Control-flow primitive
----------------------

The service stores Sounding objects in a Python list. A forged type pointer is
placed in a victim object, while a minimal fake PyTypeObject is written in the
same arena. Its +0x30 tp_dealloc field points to libc setcontext. Replacing the
list entry with None decrements the victim to zero and invokes that forged
destructor with RDI equal to the attacker-controlled victim.
