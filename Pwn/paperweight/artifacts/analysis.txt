Executable
----------
Architecture: x86-64
Type: PIE, dynamically linked, stripped C++
Mitigations: Full RELRO, stack canary, NX, PIE
Bundled Poppler: libpoppler.so.156

Protocol
--------
A || p32(size)             allocate one A-filled chunk, size 1..0x1000
F || u8(index)             free one of 32 allocation slots
B || p32(size) || bytes    cache up to 0x2000 bytes
N                          allocate one 0x100-byte Folio
P || p32(size) || PDF      render PDF through Poppler
S                          print min(Folio.length, 0x100) bytes and exit
T                          install seccomp, call Folio virtual method, exit
Q                          exit worker

The parent forks five sequential workers. All workers inherit identical
mappings; child heap mutations are copy-on-write.
